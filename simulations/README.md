# simulations/

Self-contained, AI-generated interactive simulations (Claude artifacts) created to fill gaps in the senior syllabus coverage.

Drop each simulation in here as a single self-contained `.html` file (all CSS/JS inline, no external dependencies). Once pushed and deployed, each one is added to `resources-senior.js` with a category, keywords, description, mapped QCAA syllabus topics, and an auto-generated thumbnail — the same as every other resource on the site.
